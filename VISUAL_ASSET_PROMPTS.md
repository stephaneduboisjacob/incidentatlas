# IncidentAtlas — epic visual asset prompt book

This prompt book is for generating original visual assets to give IncidentAtlas a distinctive, premium, futuristic identity. It follows the current product: a dark operational change recorder for reconstructing incidents, with a deep ink interface, quiet teal and mint highlights, restrained amber warnings, and coral failures. The visual aim is **cinematic evidence-room**, not generic cyberpunk. It should feel bold at first glance, then calm and readable during a real outage.

## Before generating

- Generate each numbered asset independently. Do not ask the model to draw a finished app screen, dashboard, charts with numbers, UI controls, text, words, letters, labels, watermarks, or a logo lockup. Build real interface elements in code; generated text and fake dashboard details become unreadable and undermine trust.
- Preserve the product palette: near-black blue-green `#101820`, raised slate `#17232C`, lighter slate `#1B2933`, fine border `#2B3A44`, mint `#79D6AD`, cool blue `#8EBDE8`, amber `#E5BD77`, and coral `#F28780`. Use glow as a small accent, never as a flood of neon.
- Keep important detail inside the central 70% safe area. Test crops at desktop, tablet, and mobile widths. On backgrounds, leave the requested copy-safe areas exceptionally quiet.
- Ask for the specified native pixel dimensions and format. Keep transparent illustrations truly transparent, with clean antialiased edges and no fake checkerboard. Export opaque backgrounds as WebP or AVIF after generation if the image service only returns PNG. Preserve the original master.
- If the model supports references, attach the existing dark IncidentAtlas screen as a palette and tone reference, not as a composition to copy. Attach the same reference to all assets in one batch for visual continuity.
- Treat all timelines, nodes, and relationship lines as **visual metaphors for recorded events and possible relevance**, not proof of causality. A human investigator confirms a cause. Avoid visual language that suggests an AI oracle has decided what happened.
