# IncidentAtlas document package / Dossier documentaire / Paquete documental / Pacchetto documenti / Пакет документации

This folder contains the user and administrator manuals, security and privacy guide, promotional kit, and FAQ in five languages. Each language folder contains the same set of documents. They describe the current early-development build. Compare operational instructions with the current deployment files and technical guides in `docs/` before applying them.
