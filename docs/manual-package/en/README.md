# IncidentAtlas documentation — English

This package is for operators and investigators using the current early-development build. The manuals describe the shipped MVP behavior; they do not imply that planned connectors or enterprise features are available.

## Documents

- [User manual](user-manual.md) — investigate timelines, evidence, hypotheses, notes, and postmortem drafts.
- [Administrator manual](administrator-manual.md) — deploy, secure, configure collectors, retain evidence, and recover the installation.
- [Security and privacy guide](security-and-privacy.md) — collection boundaries, data handling, and operational safeguards.
- [Promotional kit](promotional-kit.md) — product description, landing page copy, short posts, and usage notes.
- [FAQ](faq.md) — current capabilities, deployment, privacy, and limitations.

Product status and operational behavior can change while the project is in early development. For implementation-level details, see the repository's `docs/` guides.
