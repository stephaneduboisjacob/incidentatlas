# Documentación de IncidentAtlas — español

Este paquete está dirigido a operadores e investigadores que usan la versión actual, todavía en desarrollo. Los manuales describen las funciones disponibles; no presentan los conectores previstos como si ya estuvieran implementados.

## Documentos

- [Manual de usuario](user-manual.md) — investigar cronologías, evidencias, hipótesis, notas y borradores de postmortem.
- [Manual de administración](administrator-manual.md) — desplegar, proteger, configurar colectores, conservar evidencias y recuperar la instalación.
- [Guía de seguridad y privacidad](security-and-privacy.md) — límites de recopilación, tratamiento de datos y medidas operativas.
- [Kit promocional](promotional-kit.md) — descripción del producto, texto para la página principal, publicaciones breves y pautas editoriales.
- [Preguntas frecuentes](faq.md) — capacidades actuales, despliegue, privacidad y limitaciones.

El producto y su funcionamiento pueden cambiar durante esta etapa. Consulte las guías técnicas del directorio `docs/` del repositorio.
