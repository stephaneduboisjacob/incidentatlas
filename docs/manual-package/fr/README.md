# Documentation IncidentAtlas — français

Ce dossier s’adresse aux opérateurs et aux enquêteurs qui utilisent la version actuelle, encore en développement. Les manuels décrivent les fonctions réellement livrées et ne présentent pas les connecteurs prévus comme déjà disponibles.

## Documents

- [Manuel utilisateur](user-manual.md) — examiner les chronologies, les preuves, les hypothèses, les notes et les brouillons de postmortem.
- [Manuel administrateur](administrator-manual.md) — déployer, sécuriser, configurer les collecteurs, gérer la conservation et restaurer l’installation.
- [Sécurité et confidentialité](security-and-privacy.md) — limites de collecte, traitement des données et protections opérationnelles.
- [Kit promotionnel](promotional-kit.md) — présentation du produit, texte de page d’accueil, publications courtes et recommandations éditoriales.
- [FAQ](faq.md) — fonctions actuelles, déploiement, confidentialité et limites.

Le produit et son fonctionnement peuvent évoluer pendant cette phase. Consultez les guides `docs/` du dépôt pour les détails techniques.
