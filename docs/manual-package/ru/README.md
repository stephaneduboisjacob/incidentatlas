# Документация IncidentAtlas — русский

Этот пакет предназначен для администраторов и расследователей, использующих текущую версию на ранней стадии разработки. Руководства описывают уже реализованное поведение и не выдают планируемые коннекторы за доступные.

## Документы

- [Руководство пользователя](user-manual.md) — изучение хронологии, свидетельств, гипотез, заметок и черновиков постмортема.
- [Руководство администратора](administrator-manual.md) — развертывание, защита, настройка коллекторов, хранение данных и восстановление.
- [Безопасность и конфиденциальность](security-and-privacy.md) — границы сбора данных, их обработка и операционные меры защиты.
- [Промоматериалы](promotional-kit.md) — описание продукта, текст главной страницы, короткие публикации и редакционные рекомендации.
- [Часто задаваемые вопросы](faq.md) — текущие возможности, развертывание, конфиденциальность и ограничения.

Во время ранней разработки продукт и его поведение могут меняться. Технические подробности см. в руководствах каталога `docs/` репозитория.
